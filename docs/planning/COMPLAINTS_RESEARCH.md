# What people complain about (Hermes / models)

Research snapshot from X discourse (2026):

1. Cost shock once token usage is visible (often harness bloat, not just model price)
2. Too many skills/MCP tools loaded → huge per-turn context
3. Background/auxiliary tasks running on expensive models
4. Mid-task failures with restart-from-scratch (no checkpoints)
5. Confusion between Hermes-the-model and Hermes-the-agent
6. Subscription credits too small for agent loops
7. Blaming the model when the harness is the problem

Gap we fill: task-aware analytics + cache-aware routing advice + discount board + apply actions.
